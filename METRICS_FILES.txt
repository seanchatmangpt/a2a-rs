PROMETHEUS METRICS IMPLEMENTATION FOR OSIRIS-EDGE
=================================================

Complete metrics collection system with Prometheus support, request tracking, error monitoring,
and /metrics HTTP endpoint. Implementation follows hexagonal architecture with port trait,
Prometheus adapter, HTTP handlers, and comprehensive documentation.

KEY METRICS TRACKED
===================

Built-in Metrics:

1. http_requests_total (Counter)
   - Labels: method (GET/POST/etc), path (/api/endpoint), status (200/404/500/etc)
   - Incremented on each request completion
   - Use: rate(http_requests_total[5m]) for requests/sec

2. http_request_duration_seconds (Histogram)
   - Labels: method, path
   - Buckets: 1ms, 5ms, 10ms, 50ms, 100ms, 250ms, 500ms, 1s, 2.5s, 5s, 10s
   - Use: histogram_quantile(0.95, rate(..._bucket[5m])) for P95 latency

3. errors_total (Counter)
   - Labels: error_type, path
   - Tracked by error_tracking_middleware automatically
   - Use: rate(errors_total[5m]) for error rate

4. active_connections (Gauge)
   - Single value, updated manually
   - Use: graph current connection count

USAGE PATTERNS
==============

Basic Setup:
```rust
use osiris_edge::{PrometheusCollector, metrics_handler};
use axum::{Router, routing::get};
use std::sync::Arc;

let metrics = Arc::new(PrometheusCollector::new()?);

let router = Router::new()
    .route("/metrics", get(metrics_handler::<PrometheusCollector>))
    .with_state(metrics);
```

With Middleware:
```rust
use osiris_edge::simple_request_metrics_middleware;
use axum::middleware;

let router = Router::new()
    .route("/api", get(handler))
    .layer(middleware::from_fn_with_state(
        metrics.clone(),
        simple_request_metrics_middleware,
    ))
    .with_state(metrics);
```

Manual Tracking:
```rust
metrics.record_request("GET", "/api/test", 200, 45).await;
metrics.record_error("validation_error", "/webhook").await;
metrics.increment_counter("events", vec![("type", "webhook")]).await;
```

PROMETHEUS QUERIES
==================

Request Rate:
  rate(http_requests_total[5m])

Error Rate (%):
  (rate(errors_total[5m]) / rate(http_requests_total[5m])) * 100

P95 Latency:
  histogram_quantile(0.95, rate(http_request_duration_seconds_bucket[5m]))

Average Response Time:
  rate(http_request_duration_seconds_sum[5m]) / rate(http_request_duration_seconds_count[5m])

Requests by Status:
  sum(rate(http_requests_total[5m])) by (status)

PERFORMANCE
===========

- Counter operations: <100ns (atomic increment)
- Histogram observations: <500ns (bucket search + increment)
- Middleware overhead: <1ms per request
- Memory: ~10KB built-in metrics + ~1KB per custom metric
- Concurrency: Lock-free counters, RwLock for custom metrics only
